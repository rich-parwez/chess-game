# 🏰 Castle Chess

Castle Chess adalah aplikasi permainan catur berbasis web yang interaktif dengan estetika visual ala kastil abad pertengahan. Dibuat menggunakan HTML5, CSS3, dan JavaScript vanilla tanpa *framework* eksternal.

---

## ✨ Fitur Utama

- **Aturan Catur Lengkap**: Mendukung pergerakan semua bidak catur, validasi langkah (*legal moves*), deteksi Skak (*Check*), dan Skakmat (*Checkmate*).
- **Indikator Langkah & Sorotan**: Menampilkan titik indikator langkah yang valid, area makanan (*capture target*), dan penanda kotak asal/tujuan terakhir.
- **Panel Status Pemain**: Menampilkan giliran pemain, status Skak/Checkmate secara *real-time*, serta gambar raja tim terkait.
- **Baki Bidak Termakan (*Captured Pieces Tray*)**: Menampilkan daftar bidak lawan yang berhasil dimakan oleh masing-masing tim.
- **Promosi Pion**: Otomatis mengubah pion yang mencapai baris paling ujung menjadi Ratu (*Queen*).
- **Desain Responsif**: Tampilan adaptif yang nyaman dimainkan baik di perangkat desktop maupun perangkat seluler.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur papan dan antarmuka pengguna.
- **CSS3**: Layout Flexbox/Grid, efek *glassmorphism*, pencahayaan tema *gothic/castle*, dan media queries.
- **JavaScript (ES6+)**: Logika permainan, validasi aturan catur, manipulasi DOM, dan manajemen status papan.
- **Google Fonts**: Font *Cinzel* dan *Alegreya Sans* untuk nuansa klasik.
